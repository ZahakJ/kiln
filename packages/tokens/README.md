# @kiln/tokens

Design tokens for the Kiln UI (PLAN.md §1.2), **generated from the brand kit** (`brand/tokens.json`, imported by `tools/import-brand.sh`): CSS custom properties for the light, dark and high-contrast themes and the five apps, the same values as a typed TS object, a Tailwind 4 `@theme` block, the brand UI fonts (Figtree, Fraunces) and the bundled, metric-compatible document fonts (Liberation Sans/Serif/Mono, Carlito, Caladea).

**Public API.**

- CSS: `@kiln/tokens/index.css` (fonts + tokens, import once per app), `tokens.css`, `fonts.css`, and `theme.css` (Tailwind 4: import after `tailwindcss`). Themes: `<html data-theme="light|dark|hc">` (absent = follow `prefers-color-scheme`). App: `<html data-app="write|grid|deck|notes|home">` (`hub` = `home`) sets the kit's `--app`, `--app-solid`, `--app-on-solid`, `--app-text`, `--app-tint` and the semantic `--kiln-accent*` and `--kiln-focus-ring`. Both attributes also work on nested elements.
- Two vocabularies: the kit's own names exactly as `brand/tokens.css` defines them (`--kiln-bg`, `--kiln-panel`, `--kiln-raised`, `--kiln-sunken`, `--kiln-line`, `--kiln-ember`, `--kiln-write-solid`, `--kiln-fire-flame`, `--kiln-font-display`, …; a test checks that every one of them exists, so the mockups' CSS works unchanged), and semantic names the chrome is written against (`--kiln-bg-surface`, `--kiln-border`, `--kiln-fg-muted`, `--kiln-accent-strong`, `--kiln-shadow-3`, …), each mapped onto a kit value.
- TS: `kit` (the typed `tokens.json`), `colors`, `scale`, `derived`, `themeBase()`, `semanticColors()`, `cssVar()`, `contrastRatio()`, `parseKit()`, `BRAND_FONTS`, `DOCUMENT_FONTS`; theme runtime `applyTheme()`, `resolveTheme()`, `createThemeStore()`, `loadThemePreference()` / `saveThemePreference()` and `THEME_BOOT_SCRIPT` (inline in `<head>` to avoid a wrong-theme flash). React bindings (`ThemeProvider`, `useTheme`) live in `@kiln/ui-kit` so this package stays framework-free.

**Workflow.** `pnpm --filter @kiln/tokens generate` parses `brand/tokens.json` strictly (`src/kit.ts`: a malformed or hostile value fails with its JSON path) and rewrites `src/generated/kit.ts`, `tokens.css`, `theme.css` and `fonts.css`, formatted with Biome. The tests regenerate and diff, so drift fails; they also check that every colour is a kit colour and that every text pair passes WCAG AA in every theme. No colour is invented here: where the kit is silent (high contrast, info, overlays), values are assembled from kit colours and listed in `docs/design/kit-gaps.md`. Document fonts are fetched by `node scripts/fetch-fonts.mjs` (SHA-256 pinned in `fonts/pins.json`; `--check` runs before the tests); all fonts' OFL licences are listed in `fonts/NOTICES.json`, which `pnpm licenses:notices` folds into THIRD-PARTY-NOTICES.
