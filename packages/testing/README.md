# @kiln/testing

Shared test infrastructure (dev-only, never shipped): the .docx/.xlsx/.pptx fixture corpus, independent
oracles and image comparison for visual tests (PLAN.md §5). The round-trip fidelity scorer moved to
Rust (`kiln-testing`, WP-60); the v1.0 TypeScript scorer and the manual-fixture generator are kept
read-only in `reference/ts-core/testing/` as port oracles.

**Fixtures** (`fixtures/`):

- `<format>/features/` — generated by `python3 -I tools/make-fixtures.py --out fixtures`
  (python-docx, openpyxl, python-pptx in `~/.venvs/kiln`, created on first run). Deterministic: fixed
  seeds, dates and zip timestamps, so the committed files only change when the generator does. Covers
  styles, numbering, tables, sections, headers/footers, inline and anchored images in every wrap mode,
  text boxes, footnotes, fields, comments, tracked changes, RTL, hyperlinks; every number-format category,
  style combinations, merges, freeze panes, 300 formulas, shared/array/dynamic-array formulas, every
  conditional-format rule type, validation, tables, nine chart types, notes, names, hidden rows/sheets,
  the 1904 date system; every layout and placeholder, 60 preset shapes, groups, cropped pictures, tables,
  charts, transitions, animation builds, notes, sections, 16:9 and 4:3. `--large` adds a 100 000-row
  workbook in `xlsx/large/` (gitignored).
- `<format>/manual/` — hand-authored edge cases (written by `reference/ts-core/testing/scripts/make-manual-fixtures.ts`): minimal packages,
  foreign namespace prefixes, custom XML and opaque binary parts.
- `external/<format>/` — 30 real-world files from the Apache POI corpus, downloaded by
  `bash tools/fetch-corpus.sh` (gitignored).

**Public API:** `loadFixture(name)`, `fixturePath`, `listFixtures(format, kind)`;
oracles `convertWithSoffice(input, format)`, `convertBatchWithSoffice`, `renderPdfPages(pdf, { dpi })`
(LibreOffice through `tools/oracle-soffice.sh`, poppler `pdftoppm`), `readXlsxWithExcelJS`,
`readDocxWithMammoth`, `readWithPython` (`python/dump.py`); availability probes `sofficeAvailable`,
`pdftoppmAvailable`, `pythonAvailable` (tests that need a missing tool are skipped, e.g. on CI);
image comparison `compareImages` and `visualScore` (pixelmatch); a small PNG codec (`decodePng`,
`encodePng`, `solidImage`).

**Playwright helpers** (`@kiln/testing/playwright`, for `e2e/specs`): `openScratch(page, { text })` opens the
playground route with a scratch document, painted and focused; `typeViaProxy` types through the hidden input
proxy as a user would; `composeIme(page, steps, commit)` drives a real IME composition over CDP;
`scratchParagraphs` reads the document back from the core; `settleFrames` waits until painting stops;
`screenshotName`/`screenshotPath` follow the PLAN.md §5 convention
(`e2e/screenshots/<spec>/<name>-<light|dark|hc>-<desktop|phone|tablet>.png`, `VIEWPORTS`); `axeScan`,
`blockingViolations` and `expectNoSeriousA11yViolations` wrap `@axe-core/playwright` (WCAG 2.2 AA tags);
`layoutScan(page, { viewport, touch })` is the first version of the layout scan (clipped text without an
ellipsis, controls outside the viewport, overlapping controls, touch targets under 24 px).

Scripts: `pnpm lint`, `pnpm typecheck`, `pnpm test`, `pnpm fixtures` (regenerate the corpus).
