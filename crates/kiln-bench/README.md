# kiln-bench

Benchmarks and the performance budgets of PLAN.md §3.9. `harness` runs a scenario with warm-up and N timed iterations and reports p50/p95/min/max with peak resident memory sampled from `/proc/self/status` on Linux; `calibrate` times a fixed CPU-bound loop to derive the machine factor that scales time budgets; `scenarios` holds the benchmarks (`text-layout-1000`, `scratch-frame-production`, `ooxml-repack-large`, `recalc-full` for B8, `recalc-incremental` for B9; later work packages add `doc-open`, `xlsx-open`, `pptx-open`, `pdf-export`, `collab-apply`); `budgets` reads `bench/budgets.toml` (one row per budget id, with a 1.5× CI tolerance), evaluates it and writes the generated block of `docs/qa/perf.md`; `synth` makes deterministic inputs. The binary: `kiln-bench list`, `run <name>... [--json] [--quick]`, `calibrate`, `assert [--ci] [--budgets f] [--report f]` (also `--assert`), which exits 1 when a measured budget is missed. `cargo xtask budgets [--ci]` builds it in release mode and runs `assert`.
