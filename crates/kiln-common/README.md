# kiln-common

Shared foundations for every Kiln crate: stable identifiers (`DocId`, `NodeId`), units (EMU, twips, points, pixels), colours, geometry on top of `kurbo`, error types and feature tiers. This crate is a scaffold created by WP-50: it builds, is linted and tested in CI, and carries no engine logic yet; the work package that owns it in PLAN.md §11 fills it in.
