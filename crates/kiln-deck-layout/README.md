# kiln-deck-layout

Slide rendering for Kiln Deck: shapes, text bodies through `kiln-text`, pictures with cropping, tables and charts into a Scene, plus thumbnails, guide and snapping geometry and animation evaluation. This crate is a scaffold created by WP-50: it builds, is linted and tested in CI, and carries no engine logic yet; the work package that owns it in PLAN.md §11 fills it in.
