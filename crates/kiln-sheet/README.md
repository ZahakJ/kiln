# kiln-sheet

The Kiln Grid workbook model: workbook and sheets over a sparse columnar store, the style table, merges, names, tables, conditional formatting, validation, hyperlinks, comments, the command log for undo and formula binding. This crate is a scaffold created by WP-50: it builds, is linted and tested in CI, and carries no engine logic yet; the work package that owns it in PLAN.md §11 fills it in.
