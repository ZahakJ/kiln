# kiln-storage

What Kiln keeps beside the documents: the native bundles `.kwrite`, `.kgrid` and `.kdeck` (`Bundle`: a zip with a versioned `manifest.json`, `model.bin`, `crdt.bin`, `versions/`, `media/`, `passthrough/`; newer bundle versions are refused with a message), the autosave journal (`journal`: generation-keyed checkpoints plus checksummed operation records, a new checkpoint every 200 operations written beside the old one and switched to by the marker, which is written last, a dirty marker, `recover` reads the checkpoint the marker names and drops a torn last record), local version history (`versions::LocalHistory`: on save and every ten minutes of editing, at most 200, named versions kept), recent and pinned files (`recents::Recents`), the templates index (`templates`), the user dictionary (`dictionary`), and the app storage behind the core's `HostOp::Store*` requests (`StorageHost`, `MemoryStorage`, `store::answer`). Natively `NativeStorage` keeps one file per value, written by a writer thread in order and flushed to the disk before the next write (replaced values through a temporary file renamed over the old one), shared by every Kiln process, with an OS file lock per open journal so no two processes write or recover the same one; and `watch::FileWatcher` reports files changed by other programs; the web keeps the same areas in the Origin Private File System (`apps/web/src/host`). `kiln-session` (`src/storage`) drives it all.
