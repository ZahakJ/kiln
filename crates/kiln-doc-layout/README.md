# kiln-doc-layout

Paragraph, line and page layout for Kiln Write: tables, floats and wrapping, headers and footers, footnotes, keep and widow rules, field results, hit testing and caret geometry, producing a Scene. This crate is a scaffold created by WP-50: it builds, is linted and tested in CI, and carries no engine logic yet; the work package that owns it in PLAN.md §11 fills it in.
