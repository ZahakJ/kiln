# kiln-testing

Test support for the Kiln core, used by the format crates' tests, `kiln-cli`, `kiln-bench` and `cargo xtask fidelity` (PLAN.md §5); never shipped. `fixtures` discovers the corpus under `fixtures/` (`discover`, `find("tables.docx")`, `list_in`) and reads the manifest `parity/corpus.json` (`Corpus::load_repo`, per-file thresholds). `oracle::Oracle` wraps LibreOffice headless through `tools/oracle-soffice.sh` (recalculating profile, `convert` to pdf/csv, `opens`) and poppler's `pdftoppm` (`render_pages`), with time-outs, and reports `Unavailable` where the tools are missing. `image` loads and saves PNGs and computes perceptual pixel diffs and the page-by-page `visual_score`. `fidelity` is the round-trip scorer: format crates implement the `Roundtrip` trait (`snapshot`, `roundtrip`) and register an adapter in `formats/mod.rs` (one line per work package); `fidelity::run` scores `structural`, `text`, `visual`, `values`, `formulas`, `oracle_opens` and `byte_identical_untouched` per file against the corpus thresholds, runs the OPC passthrough baseline over every package (`fidelity::package::repack`, `compare_packages`) and renders the text and Markdown reports (`docs/qa/fidelity.md`). With no adapter registered the report says "no formats registered" and only the baseline is measured. `conformance` is the formula conformance CSV runner as a library (`load_dir`, `run` with any evaluator, exclusions, fixture sheets).
