# kiln-deck

The Kiln Deck presentation model (PLAN.md §3.4, WP-76), shaped like PresentationML. A `Presentation` holds the slide size, masters (each with its DrawingML theme, colour map, background, title/body/other text styles and its layouts), slides, sections, the notes master, the default text style and a parts store for media and charts. Shapes are geometry shapes and text boxes, pictures with crop, groups with a child coordinate space, tables, chart handles, connectors and media, with EMU transforms and kiln-ooxml's fills, lines and effects; a placeholder is any shape with a placeholder reference. Text bodies are kiln-doc paragraphs and runs (so Write's text engine, edit builders and ops are reused) with DrawingML body properties (insets, anchor, autofit, columns, wrap, direction), list styles and paragraph extras (bullets, numbering, spacing). Placeholder inheritance resolves on access — position, size, shape and body properties attribute by attribute, and text styles level by level — slide → layout → master → master text style → default text style, matched by type and index as PowerPoint does; backgrounds and colour maps inherit likewise. Transitions cover the twelve of the Transitions tab plus Morph with a fallback for every PowerPoint transition; the animation timeline has the entrance, emphasis and exit effects of the Animations tab with PowerPoint's preset ids, start modes, duration, delay, repeat, a show schedule and kept trigger sequences. Every change is a `Transaction` of `Op`s whose inverse restores the presentation exactly (checked for every op and property-tested over random edit sequences); `UndoStack` groups typing per word and explicit groups. The twelve bundled themes live in `assets/themes/` as `.kdeck-theme` files (an OOXML theme plus master and layout definitions, generated by `assets/themes/build.py`) and build the master with the eleven standard layouts. No layout or rendering here: `kiln-deck-layout` turns slides into Scenes.

## Public API

| Module | What it gives |
|---|---|
| `presentation` | `Presentation` (`new`, `with_theme`, `empty`, `alloc_id`, `slide`, `layout`, `master`, `shape`, `locate`, `shape_list`, `slide_of_shape`, `section_of_index`, `all_ids`, `validate`, `to_bytes`/`from_bytes`), `Owner`, `ShapePath`, `Part` |
| `slide` | `Master`, `Layout`, `LayoutKind` (the eleven standard layouts, custom, other), `Slide`, `Notes`, `NotesMaster`, `Comment`, `Section`, `Background`, `ColorMapping`, `SlideSize`, `HeaderFooter` |
| `shape`, `geom` | `Shape` (`text_box`, `geometry`, `walk`, `walk_text`), `ShapeKind` (`Geometry`, `Picture`, `Group`, `Table`, `Chart`, `Connector`, `Media`), `Placeholder`, `PlaceholderType`, `ShapeProps`, `ShapeStyle`, `Geometry`, `Crop`, `Table`; `Transform` (rotated `bounds`), `ChildSpace` (`child_to_parent`), `Rect` |
| `text` | `TextBody` (`from_text`, `from_paragraphs`, `paragraphs`, `text`, `level_of`, `deck_props`), `BodyProps` (`resolve`), `ListStyle`, `LevelStyle`, `DeckParaProps`, `Bullet`, `TextSpacing`, `Autofit` |
| `inherit` | `match_layout_placeholder`, `match_master_placeholder`, `Presentation::chain_of`, `resolved_xfrm`, `resolved_props`, `resolved_body`, `level_style`, `resolved_paragraph`, `resolved_run`, `resolved_background`, `resolved_color_map`, `color_context`, `shows_master_shapes` |
| `transition`, `animation` | `Transition`, `TransitionEffect` (`from_element`/`to_element` for every PowerPoint transition), `GALLERY`; `Timeline` (`schedule`, `clicks`, `badges`), `Effect`, `AnimationEffect` (`ooxml_preset`/`from_ooxml_preset`), `EffectStart`, `gallery` |
| `ops`, `undo` | `Op` (46 primitive changes), `Transaction`, `Presentation::apply` (atomic, returns the inverse), `TextTarget`, `UndoStack` (`begin_group`/`end_group`, typing per word) |
| `edit` | Builders: slides (`insert_slide`, `duplicate_slides`, `delete_slides`, `move_slides`, `move_slides_to_section`, `set_hidden`, `change_layout`, `reset_slides`, `set_background`, `set_notes_text`, `set_slide_size`), sections, shapes (`insert_shapes`, `delete_shapes`, `move_shapes`, `set_transform`, `set_shape_props`, `set_shape_info`, `set_crop`, `new_picture`/`new_table`/`new_chart`/`new_connector`), arrange (z-order, `group`, `ungroup`, `align`, `distribute`, `rotate_by`, `flip`), text (`edit_text` over any kiln-doc builder, `insert_text`, `set_text`, `set_body_props`, `set_para_extras`, `set_paragraph_level`), motion, comments, themes (`apply_theme`, `apply_variant`, `set_theme_colors`, `set_theme_fonts`) |
| `themes` | `ThemeFile` (`parse`, `build_master`, `variant_theme`), `bundled`, `bundled_theme`, `BUNDLED`, `layouts` (the standard layout grid), Kiln's default text styles |
| `dml` | DrawingML ⇄ model: `serde_xml` (serde for kiln-ooxml values), `color` (DrawingML ⇄ kiln-doc colours with tint/shade), `text` (`a:bodyPr`, `a:pPr`, `a:rPr`, `a:lstStyle` parse and write) for the `.pptx` reader and writer |

`cargo run -p kiln-deck --example theme_gallery -- themes.html <fonts-dir>` renders every bundled theme (six sample slides and the variants) as an HTML contact sheet for design review.
