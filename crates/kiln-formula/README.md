# kiln-formula

The spreadsheet formula engine: tokenizer, Pratt parser, AST, references (A1, R1C1, 3-D, structured), dependency graph, incremental multi-threaded recalculation, values, Excel number formats and the function library with its documentation. This crate is a scaffold created by WP-50: it builds, is linted and tested in CI, and carries no engine logic yet; the work package that owns it in PLAN.md §11 fills it in.
