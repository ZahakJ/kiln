# kiln-text

Fonts (bundled OFL fonts, system fonts, the Office substitution table), shaping (`parley` over `harfrust`), bidi, line breaking, hyphenation, glyph-atlas rasterisation (`swash`) and a metrics cache. This crate is a scaffold created by WP-50: it builds, is linted and tested in CI, and carries no engine logic yet; the work package that owns it in PLAN.md §11 fills it in.
