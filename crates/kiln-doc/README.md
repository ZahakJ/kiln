# kiln-doc

The Kiln Write document model, shaped like WordprocessingML: nodes, marks, the style sheet, numbering, sections, fields, footnotes, comments and revisions, with a transaction log and undo. This crate is a scaffold created by WP-50: it builds, is linted and tested in CI, and carries no engine logic yet; the work package that owns it in PLAN.md §11 fills it in.
