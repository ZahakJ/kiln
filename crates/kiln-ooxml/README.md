# kiln-ooxml

The Office Open XML foundation: OPC packages (zip), an order-preserving XML layer on `quick-xml`, namespaces, simple types, units, DrawingML (colours, fills, lines, effects, text, themes, 187 preset geometries), opaque-part passthrough, document properties and a deterministic writer. This crate is a scaffold created by WP-50: it builds, is linted and tested in CI, and carries no engine logic yet; the work package that owns it in PLAN.md §11 fills it in.
