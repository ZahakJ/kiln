# kiln-session

The facade over the whole core and the only API the shells use (PLAN.md §3.3, `docs/adr/0005-bridge.md`).

- `Session`: open documents (`new_document`, `open`), `execute` with validation against each command's `CommandMeta` (app and availability), `query`, `set_viewport`, `frame` (the next `SceneDelta` of the document's viewport, see below), `a11y`, `poll` for events and `host_reply` for deferred host requests. Open and Save/Save As run as host-request continuations, so they work over both synchronous and asynchronous hosts.
- `Host`: the outside world. `NativeHost` (desktop) reads and writes files with atomic replace and defers dialogs, clipboard and preferences to the UI; `DeferredHost` (web) defers everything.
- `SessionHandle` (native only): the session on its own thread behind a flume channel with one-shot replies, typed async methods for the Tauri IPC handlers, blocking `call`, non-blocking event subscriptions per document or for all (`subscribe`, `subscribe_as` to replace an owner's earlier stream; events nobody received yet, such as an early host request, go to the next subscriber); a panicking job fails alone, and a document it was changing is marked damaged (read-only, Save asks for a new location).
- `undo::UndoStack`: bounded history (1,000 steps, 64 MB) with coalescing and saved-state ids.
- `apps/`: the registry of document models (`DocModel`, `AppFactory`). `apps/scratch` is a plain-paragraph document (grapheme-aware editing, word motions, selections, coalesced undo, UTF-8/UTF-16 text files) that proves the loop until the Write engine exists. App work packages add one line each to `apps/mod.rs`.
- `frame` (WP-54): `FrameState` per document keeps the `DeltaTracker` that mirrors the painter's cache; a model that paints implements `FrameSource` (prepare the scene for a `FrameRequest`: visible, send = viewport + 1 viewport of prefetch, keep = + 1.5 viewports; hand out glyph-atlas rows). `GlyphCache` turns `kiln-text` glyph runs into Scene glyph quads in device pixels and tracks atlas pages to upload. `suite.view.repaint` resets the painter.
- The scratch document paints (WP-54): on its first frame or click it lays its paragraphs out with `kiln-text` (Calibri 11 pt, 1.08 lines, 8 pt after) on Letter pages with 1-inch margins, one tile per page with the page shadow, relaying out only changed paragraphs after edits. With a layout it gives caret, selection and handle geometry, hit testing (`SelectAt` by character, word with trailing spaces, or paragraph; drag extends by the unit), line-wise Home/End/Up/Down/Page Up/Page Down with a remembered column, IME composition (`SetComposition`/`CommitComposition`/`CancelComposition`, underlined, one undo step when committed), Delete and word deletion, Select All, the selected text for Copy, and an accessibility tree of the visible pages ± 1 with the caret. Golden PNGs of it (`fixtures/golden/scene/`) are checked by `cargo nextest run -p kiln-session golden` (`KILN_UPDATE_GOLDEN=1` to regenerate).
