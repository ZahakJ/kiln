# kiln-sheet-layout

Viewport layout for Kiln Grid: row and column offsets, cell painting (number formats, overflow, wrap, rotation, border precedence, conditional-format visuals), frozen panes and selection geometry, producing Scene tiles. This crate is a scaffold created by WP-50: it builds, is linted and tested in CI, and carries no engine logic yet; the work package that owns it in PLAN.md §11 fills it in.
