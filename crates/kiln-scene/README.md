# kiln-scene

The retained display list: `Scene`, layers, tiles and draw operations (rectangles, paths, glyph runs, images, clips, transforms, squiggles, carets, selection rectangles), `SceneDelta`, postcard encoding and hit-test helpers. This crate is a scaffold created by WP-50: it builds, is linted and tested in CI, and carries no engine logic yet; the work package that owns it in PLAN.md §11 fills it in.
