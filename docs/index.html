Features

Everything you use Office for

Writing, numbers and presenting, with the files you already have. Nothing has to be converted first, and parts of a file Kiln does not model are copied back byte for byte.

Opens and saves your files

.docx, .xlsx and .pptx directly, CSV, and PDF export. The Linux build adds OpenDocument. Macros stay in the file and do not run.

The layout you know

Ribbon, File menu, status bar, Key Tips on Alt and Office's common keyboard shortcuts, in a warmer design with light and dark themes.

Find any command

The command palette (Ctrl+Shift+P) searches the commands by their name here or by what Office calls them.

Version history

Kiln Write and Kiln Deck documents keep their own history on your device: name a version, preview it, restore it.

Collaboration you host

Edit Kiln Write and Kiln Deck documents together, live, through a small relay you run yourself.

3 interface languages

English, German and Arabic, with a mirrored right-to-left interface and right-to-left documents and sheets.

Apps

Three apps, one kiln

Each app is a glazed tile in the shape of a kiln arch, and each burns its own colour. All three open from Kiln Home. The pictures here are the built web app with sample documents, in your colour scheme and in the other one.

Kiln Write

Documents, for Word users

One layout engine of its own for the screen, print and PDF.

  • Styles, sections, headers and footers, footnotes, tables of contents
  • Track Changes and threaded comments
  • Markdown shortcuts as you type, focus mode and word goals
  • PDF export and printing with a preview

Kiln Write in the manual

Kiln Grid

Spreadsheets, for Excel users

Formulas in Excel's syntax, with dynamic arrays and LAMBDA.

  • 505 functions, with their arguments shown as you type
  • Charts, PivotTables, conditional formatting, sort and filter
  • Formula Lab: watch a formula evaluate step by step
  • A test sheet of 1,000,000 cells scrolls at 60 frames a second in Chromium

Kiln Grid in the manual

Kiln Deck

Presentations, for PowerPoint users

Masters, layouts and themes from the .pptx, and a slide show with Presenter View.

  • Slide show and Presenter View, with notes, a timer and the next slide
  • Transitions, animations and the Animation Pane
  • Design Ideas and charts on slides
  • Handouts and notes pages in print and PDF

Coming from Office

Feels like home

Office users will find the ribbon, the File menu and the common shortcuts where they expect them. The warmth is Kiln's own.

  • The ribbon: Home, Insert, Layout, References, Review and View in Kiln Write; Home, Insert, Page Layout, Formulas, Data, Review and View in Kiln Grid; Home, Insert, Design, Transitions, Animations, Slide Show, Review and View in Kiln Deck. Classic or simplified, and Ctrl+F1 collapses it.
  • The File menu: recent files, templates, Info, Save As, Print with preview, Export and Options.
  • The status bar, with page and word counts in Kiln Write, sums and averages of the selection in Kiln Grid, and zoom.
  • Office's common shortcuts, in a table of 59 rows, and Key Tips on Alt. End-to-end tests send each row's keys to each app as a keydown event and check the command it reaches.
  • Office's words: search the palette for “Merge & Center” or “Format Painter” and you get the command.

Under the hood

One Rust core, every window

Documents are laid out in Rust and painted onto a canvas from a display list, and the PDF comes from the same layout.

  • The core runs natively in a Tauri shell, and as WebAssembly in a Web Worker in the browser.
  • The ribbon, dialogs and panes are a thin TypeScript layer with no business logic.
  • kiln-cli converts, renders and inspects documents from a script.
$ git clone https://github.com/ZahakJ/kiln && cd kiln
$ bash tools/setup-rust.sh && bash tools/setup-node.sh
$ source ~/.profile
$ pnpm install
$ cargo xtask wasm --release
$ pnpm dev     # http://localhost:5173

$ cargo run -q -p kiln-cli -- convert \
    "e2e/fixtures/media/Annual report 2025.docx" report.pdf
