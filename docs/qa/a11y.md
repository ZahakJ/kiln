# Accessibility: WCAG 2.2 AA self-audit

Kiln Home, Kiln Write, Kiln Grid and Kiln Deck in the web app (Chromium) and the desktop
app (the same web content in Tauri's webview), audited against every Level A and AA success
criterion of WCAG 2.2. Kiln is also an authoring tool: where a criterion concerns content the user
writes (captions of a video they insert, alt text of their pictures), the row says what Kiln does
to let them meet it.

Statuses: **Supports**, **Partially supports** (what does not is stated), **Not applicable**.

Automated evidence is `e2e/specs/a11y.spec.ts` (`pnpm e2e --grep a11y`): axe-core with the WCAG 2.2
A/AA and best-practice rules, 0 serious or critical findings on Home, every app frame in light,
dark and high contrast, every ribbon tab (contextual ones in their context), every Backstage page,
every Options page, every dialog and pane any command opens (blank documents and documents with a
table, picture, chart, shape or PivotTable selected), the Text View of each app, and in a Windows
contrast theme (forced colors), with axe's enhanced contrast rule (7:1) in high contrast; a keyboard
walk that reaches every one of the build's 641 catalog commands with a visible focus indicator at
every stop; WCAG's text spacing and a 200 % zoom on every app; the Key Tips audit. The Rust tests in `kiln-doc-layout` (`tests/a11y.rs`),
`kiln-sheet-layout` (`a11y.rs`) and `kiln-session` (`a11y/tests.rs`) check that the accessibility
tree has a node, with its text or name, for every paragraph, cell and shape on screen.

## Screen reader walkthroughs

Each script is run with the screen reader's default settings and Kiln's default (light) theme.
"Says" lists what the reader announces, in order; a step passes when it does.

### Orca (Linux, Firefox or Chromium)

**Kiln Home**
1. Open Kiln. Orca says the page title "Kiln Home" and the heading "What are we making today?".
2. Press **Tab**: "New document in Kiln Write, button". **Tab** on through the doors; **H** in browse mode moves by headings (Recent, Coming from Microsoft Office?).
3. Press **Enter** on the Write door: the Write window opens and Orca says "Document1 – Kiln Write".

**Kiln Write**
1. Type "Kiln report". Orca echoes the characters. Press **Enter**, type a second paragraph.
2. Press **Shift+Home**: "…, selected". Press **Ctrl+B**: Orca says "Bold on" when it reports formatting (Orca+F reports the font).
3. Press **Alt**: "Key Tips on". Press **H**: the Home tab. Press **Esc** twice: back in the document.
4. Press **F6**: the status bar ("Page 1 of 1", then the word count with Tab). **F6** again: the title bar (Save button). **F6**: the ribbon's Home tab, "tab, selected". **Down Arrow**: the first command, "Paste, split button".
5. Press **Alt, W, T, V**: the Text View opens; Orca says "Text view, heading level 2", then the document. Use **H** for headings, **L** for lists and **T** for tables in browse mode; press **Orca+A** to read all.
6. In the Text View, switch to focus mode (Orca+A while in the text), type a word: Orca echoes it, and the page view shows it after **Close Text View**.

**Kiln Grid**
1. Open a workbook. Orca says "A1, blank".
2. Type "42": "Enter mode". Press **Enter**: "Ready mode", "A2, blank". Press **Up**: "A1, 42".
3. Type "=A1*2" in B1, **Enter**, **Up**: "B1, 84, formula =A1*2".
4. Press **Shift+Right**: "B1 to C1 selected".
5. Press **Alt, W, T, V**: the sheet as a table. Orca's table navigation (**Alt+Shift+arrows**) reads the column letter and row number with each cell.

**Kiln Deck**
1. Open a presentation. Orca says "Presentation1, slide 1 of 1".
2. Press **Ctrl+M**: "slide 2 of 2".
3. Press **Tab** on the slide: the selected shape's name ("Title 1 selected").
4. Press **F5**: "Slide 1 of 2". **Right**: "Slide 2 of 2". **Right**: "End of slide show, click to exit." **Esc** ends the show.
5. Press **Alt, W, V**: each slide is a region named "slide n of m: title", with its text, pictures by alt text and the notes.

### NVDA (Windows, Chromium-based browser or the desktop app)

**Kiln Home**
1. Open Kiln: NVDA reads "Kiln Home" and the main heading. **H** moves by headings, **B** by buttons.
2. **Enter** on "New workbook in Kiln Grid": NVDA says "Book1 – Kiln Grid".

**Kiln Write**
1. Type two paragraphs. NVDA echoes characters (or words). **NVDA+Up Arrow** reads the current line.
2. **Shift+Ctrl+Left**: NVDA says the selected word and "selected".
3. **Alt**: "Key Tips on". **N**: Insert tab. **T**: Table opens its picker; **Esc** back.
4. **F6** around the window: status bar, title bar, ribbon ("Home tab, selected, 1 of 7"), document.
5. **NVDA+End** reads the status bar.
6. **Alt, W, T, V**: the Text View. In browse mode: **H** headings, **L** lists, **T** tables (with row and column headers), **G** pictures (their alt text). **NVDA+Space** for focus mode, then type: the page view follows.
7. **Ctrl+Shift+F** (Font dialog): NVDA reads "Font, dialog" and the first field; **Tab** through; **Esc** returns to the document.

**Kiln Grid**
1. Move with the arrows: NVDA reads "B3, 1,284.00" (and the formula when there is one) at each move.
2. Type: "Enter mode"; **F2**: "Edit mode"; type **=SUM(** and press an arrow: "Point mode".
3. **Ctrl+Shift+Down** from a column of values: "B2 to B11 selected".
4. **Shift+F10**: the cell's context menu; arrows read each command.

**Kiln Deck**
1. **Ctrl+M** adds a slide: "slide 2 of 2". **Page Up**: "slide 1 of 2".
2. **Tab** cycles through shapes: their names are read as each is selected ("Picture 3 selected").
3. **F5**: the slide show reads each slide's number as it appears; **B** reads "Black screen".
4. **Alt, W, V**: the Text View; **D** moves by regions (one per slide).
