# Kiln design: the brand kit and the mockups

The design team's brand kit is the visual source of truth for everything user-facing (PLAN.md §1.2).
It is imported verbatim into [`brand/`](../../brand/) by [`tools/import-brand.sh`](../../tools/import-brand.sh),
and its guide is [`brand/BRAND.md`](../../brand/BRAND.md). Nobody invents colours or type: where the kit
is silent, follow the mockup, then Office's layout, and add the gap to [kit-gaps.md](kit-gaps.md).

## What the kit feeds

| Kit file | Becomes | How |
|---|---|---|
| `brand/tokens.json` | `packages/tokens` (`tokens.css`, `theme.css`, `fonts.css`, `src/generated/kit.ts`) | `pnpm --filter @kiln/tokens generate`; a unit test regenerates and diffs, so drift fails |
| `brand/fonts/` (Figtree, Fraunces, OFL) | `assets/fonts/brand/<Family>/` with `OFL.txt` | `@font-face` in `packages/tokens/fonts.css` |
| `brand/icons/mono/`, the spark and flame in the mockups | `packages/ui-kit/src/icons/brand/marks.generated.ts` | `<AppGlyph>`, `<Spark>`, `<Flame>`, `<Icon icon="brand:…">` |
| `brand/icons/svg/<app>{,-48,-32,-16}.svg` | `packages/ui-kit/src/icons/brand/tiles/` | `<AppTile app size>` picks the level of detail drawn for the size |
| `brand/icons/png`, `macos`, `windows`, `android/` | `apps/desktop/src-tauri/icons/` (`pnpm tauri icon`, plus the kit's per-size drawings, a reproducible `.icns` and `.ico`) | `tools/import-brand.sh`, `tools/render-media.mjs` |
| `brand/favicon.*`, `brand/icons/png` | `apps/web/public/` (favicon, PWA icons 16–1024, maskable 192/512, `manifest.webmanifest`) | same |
| `brand/banner*.png/svg`, `social-preview.*`, lockups | `docs/media/` (README banner, landing page hero, `og:image`) | same |
| `brand/mockups/*.png` | `docs/design/mockups/` (below) | same |

## Re-importing a new kit

```sh
tools/import-brand.sh                          # from /home/muth/kiln-brand/final
KILN_BRAND_KIT=/path/to/final tools/import-brand.sh
tools/import-brand.sh --no-kit                 # regenerate from the committed brand/ only
pnpm --filter @kiln/ui-kit shots               # review sheets: packages/ui-kit/stories/out/primitives-{light,dark}.png
```

The script is idempotent: a second run leaves `git status` unchanged.
